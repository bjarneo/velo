# A speed test for your terminal.

# velo measures latency, download, upload, and bufferbloat against the nearest speedtest.net server. It shows each phase live, in the colors of your Omarchy theme.

~ ❯ curl -fsSL https://raw.githubusercontent.com/bjarneo/velo/main/install.sh | sh

# Add velo to the Omarchy launcher. Then press Super + Space and type velo.

~ ❯ omarchy-tui-install velo velo tile https://raw.githubusercontent.com/bjarneo/velo/main/assets/icon.png

# Run a test. A test takes about 20 seconds.

~ ❯ velo --private

# Six flags. velo starts a test without any.

~ ❯ velo --help 
usage: velo [flags]

  -demo
    	simulate the network instead of testing it
  -no-autostart
    	wait for ⏎ instead of starting a test
  -private
    	mask the client IP address, for screenshots and recordings
  -server string
    	use the speedtest.net server with this id, as the server list shows it
  -theme string
    	start with this theme, for example "nord"
  -version
    	print the version and exit

themes: omarchy, tokyo-night, catppuccin, gruvbox, nord, everforest, kanagawa, rosé-pine, matte-black

# How velo measures. Each value has a documented method.

~ ❯ less docs/measurement.md
SEQUENCE the run in the recording
  1. 01LATENCY4.0 ms ✓

    24 HTTP probes on one warm connection. Ping is the mean time. Jitter is the mean change between 2 probes.

  2. 02DOWNLOAD495.8 Mbps ✓

    16 streams for 8 seconds. velo counts the bytes that it reads and takes a sample every 50 ms.

  3. 03UPLOAD495.6 Mbps ✓

    16 streams for 7 seconds. On Linux, velo counts only the bytes that the server acknowledged.

  4. 04ANALYZEgrade C ✓

    A latency probe every 250 ms under load. Bufferbloat is the loaded latency minus the idle latency.
